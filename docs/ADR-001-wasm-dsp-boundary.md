# ADR-001: граница Vanilla JS vs Rust/WASM в PUMP

Дата: 26.11.2026. Статус: принято. Основание: измерение, а не предположение
(`web/bench/*`, `tests/bench_dsp.py`, `web/bench/baseline.json`).

## Контекст

Одинаковый тракт (10 RBJ-биквадов transposed-DF2 + preamp, `crates/audio-dsp-engine/src/eq.rs`
vs `web/bench/js-dsp.js`) прогнан в HeadlessChrome 153 бок о бок: 3 прогона +
1 прогон с 4x CPU-throttle, 15 пачек x 256 блоков x 128 фреймов, warmup 3 пачки,
детерминированный вход (xorshift). WASM: `web/pkg/pump_dsp.wasm`, ABI v1
(`config_len=57`, `capacity=2048`).

## Факты (после симметризации копирования входа, 26.11.2026)

- Холодный старт: compile 0.4 мс + instantiate 0.2 мс (без throttle);
  1.3 мс + 0.5 мс при 4x throttle.
- Размер WASM: 61951 байт raw, 25154 байт gzip (40.6%).
- Core (ядро, нс/фрейм, p50 / p95 / p99):
  JS 103.76 / 231.93 / 231.93; WASM 54.93 / 155.64 / 155.64.
  Отношение 0.529 — WASM быстрее в 1.89 раза. xRT медианный: JS ~201, WASM ~379.
- Full (с границей JS/WASM): JS p50 103.76, WASM p50 57.98.
  Накладные расходы ABI: +3.05 нс/фрейм (+5.6% к ядру WASM).
- Память: Linear Memory 1638400 байт до и после, `mem_grew=false` во всех прогонах.
- CPU-throttle 4x: JS p50 460.82 нс, WASM p50 241.09 нс (отношение 0.523);
  xRT 45.2 vs 86.4 — соотношение то же, вывод не артефакт быстрой машины.
- Идентичность: `checksum_rel_diff = 0` во всех 4 прогонах (3 + throttled).
- Квант 128 фреймов = 2.67 мс: блок WASM ~7 мкс, JS ~13 мкс — оба < 0.5% ядра.

## Решение

1. EQ-ядро остаётся в Rust/WASM (уже там, корректно, быстрее в ~1.9 раза).
   Мелкие задачи (UI-состояние, очередь, подсветка слов, комнаты) остаются в JS:
   при бюджетах < 0.5% кадра перенос в WASM не окупает ABI и сложность.
2. Новый compute-heavy анализ (STFT/chroma/onset/BPM/key/LUFS, SIMD-дружелюбный)
   — Rust + realfft в независимом ядре без Tokio/Axum/DOM (`audio-dsp-engine`,
   feature `analysis`). WASM-интеграция анализа — только после цифр native/WASM
   паритета на том же ядре.
3. Пороги: `checksum_ok` обязателен; perf-медианы из `baseline.json` —
   ориентиры, тревога при регрессе > 2x к медиане (предупреждение, не gate).

## Что не делаем

- Не тащим DOM/Tokio/Axum/Telegram в вычислительное ядро.
- Не выдаём синтетические фикстуры за доказательство качества на реальной музыке
  (для реальной музыки — отдельный размеченный набор и отдельное измерение).
