# ADR-002 — независимое ядро анализа аудио (GATE 2)

Дата: 26.11.2026. Статус: реализовано, тесты зелёные, ревью назначено.

## Контекст

Automix (GATE 3) требует BPM/beatgrid/key/LUFS/секции/точки микширования.
Старый `analysis.rs` (`analyze_track`) — эвристика на огибающей с prior 120 BPM,
без STFT/chroma/key/beatgrid. Нужен профессиональный задел без сноса рабочего.

## Решение

Новый модуль `crates/audio-dsp-engine/src/music_analysis.rs` за feature `analysis`
(`dep:realfft 3.5.1`):

- Только `std` + `realfft`. Нет Axum/Tokio/DOM/Telegram. Проверено:
  `cargo check --target wasm32-unknown-unknown` — чисто; native/WASM — один код,
  детерминирован (фиксированные окно 4096/шаг 1024/Hann, без RNG).
- STFT → flux (фикс. лог-компрессия) + kick-band 160 Гц + ВЧ-контроль >2 кГц →
  onset (median+2·MAD, ≥0.15·max, ≥80 мс) → автокорреляция темпа 50–220 BPM
  с параболой (<1%) + октавный снап по IOI сильных долей (значение — от
  автокорреляции, IOI задаёт только октаву) → фазовый beatgrid (конвенция
  aubio: метка onset = конец кадра) → HPCP-chroma (только пики + парабола,
  вес энергией, октава 0.3, без 3f) → ключ KS с лог-компрессией →
  LUFS (существующий `LoudnessMeter`) + true peak 4x-линейный →
  кривая энергии/RMS-100мс, тишина −60 dBFS/200 мс, секции жадной
  кластеризацией (косинус ≥0.93, cap 8, слияние соседей — не равномерная
  нарезка), переходы MixIn/MixOut/SectionBoundary/EnergyDip.
- Память: вход — срез (единственная копия — моно-микс), хранятся только
  chroma+энергия на STFT-кадр (13 f32); лимит входа 14.4M фреймов (~300 с 48 кГц);
  FFT-план и буферы переиспользуются в `MusicAnalyzer`, есть `reset()`.
- Отмена — `&AtomicBool` (проверки каждые 32 STFT-кадра + перед автокорреляцией);
  `Error::Cancelled`. Версия результата `ANALYSIS_VERSION = 1`.
- Гейты честности: крест-фактор ≥3.0 (синкопа 3.9 проходит, шум 2.8/сустейн 2.0 —
  нет), ВЧ-гейт hf_ratio ≥0.02 (гул без транзиентов — нет), уверенность BPM ≥0.35,
  ключ только при r1 ≥0.55.

## Факты приёмки (синтетика, `cargo test -p audio-dsp-engine --features analysis`)

- BPM 60/85/90/120/128/140/160/174: ошибка ≤1% (октавный снап, парабола).
  Half/double-time (кик+хэт), weak-клики, синкопа, 44.1/48/96 кГц, стерео — те же ≤1%.
- Дрейф 120→140: оценка внутри диапазона, без panic.
- Beatgrid: медианная ошибка ≤20 мс (конвенция конца кадра; было ~100 мс из-за
  опережения окна на 85 мс — исправлено измерением, а не подгонкой).
- Ключ: C/G-major, A/E-minor на триадах — 100% (пики+парабола+лог-компрессия;
  было E-minor вместо C-major из-за голосования всех бинов и 3f-гармоник).
- LUFS: streaming vs независимый эталон BS.1770 в тесте — расхождение ≤0.5 LU.
- Пусто/NaN/коротко/отмена: без panic (`Invalid`/`Cancelled`).
- Старый `analyze_track` не тронут (стабилизированный компонент).

## Что не утверждаем

Синтетика ≠ доказательство качества на реальной музыке: для неё нужен
размеченный набор и отдельное измерение (явный пункт 2.5 ТЗ). Пороги 3.0/0.02/0.35
калиброваны на синтетике; рекалибровка — по реальному набору.
