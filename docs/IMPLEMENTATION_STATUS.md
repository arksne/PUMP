# Сверка PUMP с ТЗ

ТЗ выполнено частично. Наличие библиотеки, сборка feature и проверка функции в интерфейсе обозначают разные уровни готовности.

| Модуль | Реализовано и подключено | Что требуется завершить |
| --- | --- | --- |
| core-streaming | Локальная музыка с тегами, iTunes preview, поиск YouTube, SAPISIDHASH, прямые форматы и резервные кандидаты, HTTP Range, история поиска, SoundCloud progressive, публичный Audius API, параллельный общий поиск | Живые проверки полных потоков, YouTube signatureCipher/n-signature/POT, полный каталог категорий и настроений |
| audio-dsp-engine | Rust PCM/DSP, Symphonia, Rubato/WSOLA, EQ/AutoEq, анализ громкости/тишины/BPM, алгоритмы сведения и DJ-сортировки. В Mini App работают EQ, Concert Mode, live pitch, скорость, очередь и sleep fade. В ветке релиза подключены двухдековый Crossfade и локальный Automix на основе `music_analysis` (BPM/beatgrid/key/LUFS), API анализа и кэш | Финальная проверка CI, измерения качества сведения, нагрузки, нативного вывода и Cast/DLNA на устройствах; расширенный DJ-режим и анализ внешних потоков |
| lyrics-engine | LRCLIB и lyrics.ovh параллельно, LRC/Enhanced LRC/TTML, слова и вокалисты, RAF-подсветка, пользовательский шрифт/blur/glow, привязка к длительности, перекрывающиеся вокалы, индекс событий, локальное смещение | Проверка на большом наборе реальных дуэтов и фоновых мобильных WebView |
| library-storage | SQLite сессий и статистики, атомарные загрузки с тегами/текстами/обложками, сканер, IndexedDB offline и local-only, загрузка всей очереди/импортированного списка с отменой и резервными форматами, API пользовательских обложек, NAS-потоки | Редактор обложек в UI, NAS-файловый браузер, проверка SMB на NAS |
| social-integrations | Комнаты WebSocket с оценкой часов, запланированным стартом и коррекцией скорости, публичный импорт Spotify и CSV без Client ID, PKCE API, Last.fm с повторной отправкой, Discord IPC API, локальные FFT-отпечатки, AudD API | Измерение синхронности на реальных устройствах, живые проверки Last.fm/OAuth/AudD с аккаунтами, полный импорт Apple Music через MusicKit, подключение Discord к работающему клиенту |
| plugin-spine | Wasmtime ABI с лимитами, поиск/resolve/качества, источник в UI, проверенный прокси, независимые ссылки/Range, переход к резервному формату. Собираемый Rust/WASM-провайдер SoundHelix | Сетевые host-вызовы для динамических провайдеров, удобный менеджер установки и настройки |
| telegram-bridge | Teloxide/Axum, HMAC initData, команды управления Mini App, inline MP3 медиатеки, комнаты, PNG-статистика, приём voice/video_note для AudD | Пользовательская проверка всех команд в Telegram. Inline требует включения в BotFather, глобальное распознавание требует токена AudD |
| ui-liquid-glass | Исходная Liquid Glass основа, пять дизайнов, анимированная обложка, палитра, шторки, safe area/haptics, настройки/поиск/шрифты/иконки/split view, Rust DSP AudioWorklet | Перенос оставшейся логики интерфейса с JavaScript на Rust/WASM, системные виджеты, завершение перечисленных выше экранов |

Облачная постоянная БД и файловое хранилище отложены до заключительного этапа по решению пользователя. Текущий сервер хранит данные локально. Неподключённые внешние аккаунты и физические устройства не считаются проверенными.

Для этой итерации проверяются `cargo test --workspace --locked`, Clippy со всеми features, браузерные сценарии воспроизведения/комнат/статистики/offline/CSV/NAS/плагинов, ABI Rust DSP и отдельного музыкального WASM-провайдера. Публичный Spotify Embed дополнительно проверен сетевым запросом без Client ID. Доступность и полнота Embed зависят от Spotify, интерфейс сообщает об усечении.

Релизные критерии, доказательства и ограничения: [RELEASE_GATES.md](RELEASE_GATES.md). Новые функции в рабочей ветке не считаются проверенными до успешного CI и соответствующих живых испытаний.
