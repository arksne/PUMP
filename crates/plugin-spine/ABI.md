# ABI музыкального провайдера PUMP

Модуль экспортирует `memory`, `plugin_abi_version() -> i32` со значением `1`, `alloc(length: i32) -> i32`, `search(pointer: i32, length: i32) -> i64` и `resolve(pointer: i32, length: i32) -> i64`.

Хост вызывает `alloc`, записывает JSON UTF-8 в память и передаёт его адрес и длину функции. Ответ находится в той же памяти. Старшие 32 бита результата содержат адрес, младшие 32 бита — длину ответа. Каждый вызов создаёт отдельный экземпляр модуля, поэтому освобождение гостевой памяти между вызовами не требуется.

Структуры запросов и ответов определены в `src/model.rs`. Для поиска используются поля `abi_version`, `query`, `limit`. Ответ содержит `abi_version` и `tracks`. Для получения потока используются `abi_version`, `track_id`, `quality`, ответ содержит `abi_version` и `candidates`.

Файлы WASM загружаются из папки `PUMP_PLUGIN_DIR`. Имя файла становится ID провайдера. API предоставляет `/api/providers`, `/api/providers/{id}/search?q=...` и POST `/api/providers/{id}/resolve`.

Модуль исполняется с ограничениями памяти, топлива и времени. Сетевые и файловые импорты хоста отсутствуют. Провайдер может работать с встроенным каталогом и возвращать ссылки. Для самостоятельного сетевого поиска модулю понадобится отдельный контракт хостовых вызовов.


## Воспроизведение в Mini App

Метаданные трека в API включают `provider: {provider_id, track_id}`. Это позволяет повторно получить временный поток из очереди, избранного или комнаты. После `resolve` сервер возвращает `track`, `urls`, `primary` и `fallbacks`. Все аудиоадреса в ответе принадлежат PUMP. Для прокси обязательно задаётся `PUMP_PLUGIN_ALLOWED_HOSTS`.

Кандидаты одного разрешения хранятся неизменно 15 минут. Повторное разрешение создаёт новую группу ссылок. Range относится к конкретному кандидату, поэтому сервер не меняет формат под уже выданным URL. При сбое клиент открывает URL следующего кандидата и восстанавливает позицию по времени. Редиректы и неаудио ответы источника отклоняются.

Собираемый пример на Rust находится в [providers/soundhelix](../../providers/soundhelix), инструкция — в [providers/README.md](../../providers/README.md).
